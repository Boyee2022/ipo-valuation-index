AS-IS · 逐券 pipeline d06a5ed
  • 执行单元 = 券。1 券 = 4 次子进程（引擎 600s / 统计 1200s / 报告 600s / 机检 300s）+ 1 次进程内组装。
  • 方法在券内串行。DCF → 可比 → 舆情，同一批券的同一方法被重复调度 50–2,201 次。
  • 并行只在最外层。ThreadPoolExecutor，parallel ∈ {3,10}；服务是单进程 ThreadingHTTPServer，全市场 2,201 只的中间态都在同一进程里。
  • 跨券信息每券重算。行业分位、可比长名单、指数权重都在单券内部现拼。
  • 状态。state.json 全量重写；>800 行时每 10 行落盘；无逐券计时。
  • 评审只在一批之内。三专家 + 主审，shadow / apply；参数只保留当前一版，无跨批台账。
TO-BE · 分层向量化 TARGET
  • 执行单元 = 方法。一层一次，V_m = f_m(X; θ_m) 对全部企业一次计算。
  • 层间 barrier。全市场 DCF / RIM 完成才进可比；非基础层（舆情 / 覆写 / 评审）异步 join。
  • 宽表 + 掩码。X(N×F)、M(N×3)；失败粒度是「方法 × 券」的单元格。
  • 产物分级。层产物 / 行产物 / manifest（as_of、参数 hash、跳过清单）。
  • 模型履历。每券 model_trace.json：方法树、参数溯源、证据链、敏感度。
  • 参数台账。T 日评审 → 主审判适用 → T+1 默认参数 P_{v+1}；可回放、可回滚。

L1 · 建模流程的解耦与向量化 DECOUPLE / VECTORIZE · W3–W6
问题 / Problem

一只券跑完整 pipeline，方法在券内串行；同一批券的同一方法被重复调度 50–2,201 次，跨券信息（行业分位、可比长名单）只能每券重算。结构上做不到「一层对所有企业统一处理」。

方案 / Approach

(a) 基础层（客观数据）：DCF / RIM / DDM / NAV / 相对估值抽成纯函数，对全部企业一次计算，层间 barrier。(b) 非基础层：舆情、rNPV、个股覆写、LLM 评审逐券单独调度，sidecar 合并，不设 barrier。

VECTORIZED FORM X ∈ R^(N×F) 财务块 | 行情块 | 行业块 | 政策块 V_m = f_m(X; θ_m) ∈ R^N 第 m 个方法一次算完 M_m ∈ {0,1}^N 有效性掩码（缺数据 / 路由否决 / 越界） DCF（显式期 T_i 因券而异，填充 + 掩码） V_dcf,i = Σ_{t≤T_i} FCFF_{i,t} / (1+r_i)^t + TV_i / (1+r_i)^{T_i} 合成（三方法 + 掩码 + 重归一） V* = ((W ⊙ M) · V_methods) / ((W ⊙ M) · 1)
PSEUDOCODEX, M0, meta = universe.build(as_of, index) # 一次装配 V, M, D = {}, {}, {} for m in ("dcf","rim","ddm","nav","rel"): # 层内按方法 V[m], M[m], D[m] = KERNEL[m](X, THETA) # 一次算 N 只 store_layer(job, "base", m, V[m], M[m]) # 层产物 + 参数 hash side = schedule_per_stock(X, M0) # 非基础层：逐券异步 V["sent"], M["sent"] = join_sidecar(side, key="secucode") Vstar, interval, why = pool.combine(V, M, W, mode=POOL) rows = merge_rows(V, M, D, side) # 行产物 = join
接口与数据结构

宽表 universe.<as_of>.jsonl + 列块元数据；层产物 layer_outputs/<method>.json；行产物 rows/<code>.json；任务级 manifest.json（as_of、代码版本、参数 hash、行数、跳过清单、层耗时）。 缓存键从「资源名」升级为「资源名 + as_of + 参数 hash」；state.json 只存索引与摘要。

编排 · 内存 · 隔离

基础层内 chunk 流水（建议 200 只），层间 barrier；非基础层不设 barrier，并行后 join。N=2,201、F≈60 的宽表约 1.1MB，内存主项是 MC（3000 次抽样必须分块，数十 MB 级，待实测）。失败隔离用行级掩码 + 行级 error：单券异常只置 M_m,i = 0；整层异常才降级 legacy。

但非基础层不能矩阵化。舆情 1 次 + 评审 4 次 LLM 调用/券，默认并发 6，2,201 只券在单进程里不可能全量跑——全市场只走规则舆情，评审按「权重 top-N + 低置信 + 极端偏离」分层抽样。

断点续跑。行级 status 已随 state.json 落盘（>800 行每 10 行一次）；原任务目录只增 layer_outputs/、rows/、manifest.json，层产物按 (as_of, method, params_hash) 幂等，重启从最后完成 chunk 续跑，旧 runtime/jobs 任务仍可读。

验收 / Acceptance

同 as_of、同参数下覆盖率与跳过率与 legacy 逐券一致；11 组 examples + 170 个用例数值零回归（逐位或 |Δ| ≤ 1e-9）；单券耗时中位 ↓≥30%（待测）；内存 ≤1.5× 基线（待测）；四类故障注入只掩码目标券；杀进程重启可续跑。

风险 / Risk

零回归是最大风险；向量化把「分支」变「掩码」，生命周期路由、Layer 0 否决、夹断最易漏；内存放大；调试可读性下降。依赖：引擎可 import、是否引入 numpy、宽表 as_of 一致。

L2 · 建模表达与可视化 EXPRESS / AUDIT · W7–W9
问题 / Problem

工作台只给中枢、区间、置信度一句备注、basis、前 6 条 warning。看不到：为什么选这个方法（Layer 0 路由 / 生命周期判定在引擎内部）、参数从哪来、可比剔除台账、stat.json 的弹性与 MC 分位、两批之间到底哪个参数变了。

方案 / Approach

每券产出 model_trace.json：方法树（候选 → 选中 / 否决 + 理由）、参数溯源（data / industry_base / override / agent_apply / skill_default）、证据链（可比 / 财务 / 舆情）、敏感度与区间（±1σ 弹性 + MC 分位 + 三情景）。

接口

model_trace.schema.json v1；工作台新增「模型履历」抽屉（左方法树 / 右证据）；逐券报告改为消费同一 JSON 渲染；diff(trace_a, trace_b) 支撑两批对比。

验收

trace 覆盖率 100%；数值与引擎输出逐位一致（派生，不重算）；参数可点回来源；任改一个参数在 trace 中可见；两批 diff 可列出「哪只券哪个参数变了」。

风险

双写不一致；字段膨胀（trace 独立文件，不进 state.json）；报告与工作台再次渲染漂移。依赖：引擎诊断结构化。

L3 · Agent 评估与参数迭代 AGENT LOOP · W10–W13
问题 / Problem

shadow 只做「批内逐券评审 + 人工采纳」；参数只有当前一版（版本号自增、明确不做跨批台账）。「昨天通过的参数今天用」不存在；没有人对评估 Agent 的意见做适用 / 不适用判定；没有收敛与振荡判据。

方案 / Approach

三角色分工：专家提建议 → 评估 Agent 把当日建议聚类成参数议题（方向 / 证据覆盖家数 / 离散度 / 行业）→ 主 Agent 判适用 / 不适用 / 观察，写入台账。次日跑批默认读台账最新已生效版本。

STATE MACHINEP_v = {weights, wacc_pp, tg_pp, caps, pool_mode} + meta{v, created, source_job, verdicts, approved_by, hash} proposed → evaluated → approved | rejected | expired → applied → superseded | rolled_back T 日 09:00 跑批(P_v) → 10:00 评审 → 10:30 评估汇总 → 11:00 主审裁决 → T+1 09:00 跑批(P_{v+1})
收敛 / 振荡 / 指标

稳定：连续 k 期同方向且 |Δ| 递减 → converged，冻结 4 周。 振荡：4 期内方向翻转 ≥2 次，或周环比中位 |Δ| 不降 → freeze + 人工介入 + 回退上一 converged 版本。 判据复用 shadow.metrics：dispersion（中位 / IQR）、wow（同指数上期共同券中位绝对变动）、adoption.rate。

shadow / apply / 回滚 / 审批

保留 off / shadow / apply 三档；跨批只经台账传参，apply 仍只在单批内回写输入。 台账写入前快照；若 P_{v+1} 跳过率上升超阈值、或 apply 后 |Δ| 超 caps，自动回 P_v 并标 rolled_back。 审批点：版本晋升需一次点击确认；caps / gate 变更走 AgentsPage 严格校验；池子切换需主审 + 人工双确认。

验收

给定 v 可完整还原参数与来源；次日默认 = 最新 approved（自动化测试）；apply 失败回滚零泄漏；构造序列能触发振荡检测。

风险

LLM 随机性（固定温度 / 种子并记录）；成本（每券 5 次 × 2,201 券不可行，需分层抽样）；自指偏差；参数漂移。

L4 · 指数选择与估值拟合 INDEX FIT · W14–W17
问题 / Problem

五指数是「选一个跑一批」，指数层只有 P × Σw(V/P)/Σw 一条公式；三情景点位由逐券区间端点合成后与点位夹逼，不是同情景一致加总；权重口径三套（官方 WEIGHT / 自由流通市值 / 总市值；上证综指剔除 ST 与未满计入期新股）；无交叉校验、无偏差分解。README 的「权重因子×当日市值」尚未实现，不当作现状。

方案 / Approach

独立 index_fit：口径 A 保留（零回归锚点）；口径 B 用加权最小二乘估系统性偏离 α；三情景同权加总并强制单调；权重口径显式标注 + 双口径 ΔP；上证50 ⊂ 上证180 ⊂ 上证综指做成分包含一致性检验。

FIT口径 A（现口径） P_A = close × Σ w_i (ps_i / close_i) / Σ w_i 口径 B（拟合） r_i = ps_i / close_i = α + β·log(mcap_i) + γ·行业固定效应 + ε_i α_w = Σ w_i · r̂_i / Σ w_i P_B = close × α_w 三情景一致 P_bear ≤ P_base ≤ P_bull （同一权重、同一池子）
验收

五指数同日并列表；情景点位单调；权重口径标注 100%；交叉一致性通过或每条差异有解释；偏差可分解为 α + 权重效应 + 残差。

风险

N=50 时回归过拟合（行业固定效应 + 收缩）；包含关系会直接暴露计算权重与官方权重的差异；指数收盘时点与成分 as_of 不同日。依赖：行级产物含 mcap / industry / weight。

L5 · 线性池 vs 对数池 vs 专家乘积 POOL · W14–W17
问题 / Problem

现在只有加权算术平均：方法分歧大时（DCF 与可比差 3 倍）被大值主导；区间端点线性加总不满足尺度不变；没有「什么时候换池子」的判据。

方案 / Approach

三种池子全部实现，评估 Agent 按「方法间离散度 + 是否同号 + σ 是否可用」提议、主审复核并记录 pool_choice + reason；单批可逐券切换，但指数层必须报告池子分布，且三情景同一池子。

THREE POOLS线性池 V = Σ w_m V_m / Σ w_m 对数池 log V = Σ w_m log V_m → V = Π V_m^(w_m) 专家乘积 p(V) ∝ p0(V) · Π p_m(V)^(w_m) 正态近似：V* = (Σ w_m V_m / σ_m²) / (Σ w_m / σ_m²)，1/σ*² = Σ w_m / σ_m² 区间（模糊）传递 线性池 [Σ w·a_m , Σ w·b_m] 对数池 [exp(Σ w·ln a_m) , exp(Σ w·ln b_m)] 乘积池 [V* − z·σ* , V* + z·σ*] （σ_m 须先校准）
池子数学性质适用不适用
线性 算术均值；可加可分解；对离群线性放大 方法数 ≤2、分歧小（IQR/中位 <30%）、需按方法分解 单方法极端值；跨行业尺度差异大
对数 几何均值；尺度不变；对低值更敏感（下行保守） 同号且量级差 >2×；乘数型方法为主 有 ≤0 值（需 mask/nudge）；需线性加总到指数
乘积 精度加权；方差收缩；需概率解释 每方法有校准 σ / 区间；方法近似条件独立 σ 未校准；方法高度相关（重复计信息）
切换策略与实验

默认线性（零回归）；评估 Agent 提议 → 主审复核 → 记录理由。 实验：同一 as_of 三池并算（离线 shadow，不进生产），比较与收盘偏离分布、周环比稳定性、极端券（估值/价 ≥5×）占比、MC p5–p95 是否覆盖收盘；跑满 4 周再定默认池子。

验收

三池可切换、可复算；区间单调且覆盖；选择有 reason 且可审计；线性池与现引擎逐位一致。

风险

对数池遇负值 / 缺失的定义（mask 与 nudge 引入人为偏移）；乘积池 σ 未校准会系统性收窄区间；池子选择的可解释性。
