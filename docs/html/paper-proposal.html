01

问题与三重模糊

PROBLEM

估值系统面对的不是“输入确定、模型确定、目标确定”的优化问题，而是三重模糊： 输入模糊（口径、缺失、时点）、模型模糊（方法边界、生命周期、路由）、 目标模糊（没有真值，价格不是价值，指数收盘不是答案）。

输入模糊 INPUT

财报口径、数据缺失、新股/ST、可比不足、舆情真假、时点不 PIT。

当前：四层取值阶梯（L1 表述 → L2 采集 → L3 问询 → L4 默认）；缺失则跳过或降置信度。

前视偏差 幸存者偏差
模型模糊 MODEL

DCF、可比、舆情、RIM、DDM、NAV、rNPV、SOTP 各有适用边界；生命周期判别本身有误差。

当前：Layer 0 前提门 + 六阶段生命周期 + 方法路由 + 三路加权；不可用方法剔除后按剩余权重再归一。

路由误判 权重主观
目标模糊 OBJECTIVE

没有真值；市价≠价值；指数收盘≠“正确答案”；“准 / 稳 / 可解释 / 可审计”互相冲突。

当前：差异只诊断、不反向校正；多指标三角验证；不以贴近收盘为目标。

循环论证 指标争议
POSITION · 不把“贴近指数收盘”当目标 设诊断残差 e_i = V_i / P_i − 1，它只用于解释偏离方向、截面分布、行业集中度与点位贡献； 不据此改写 V_i，也不把 P_i 当监督信号。价格含噪声与情绪，以收盘为目标会把“复制指数”当成“估值”。
相关工作与方法论来源 RELATED WORK

据技能包 methodology.md 的文献映射，llm-ipo-valuation 的方法论来自 国金证券李双宏、杨利国、王洪涛《基于大语言模型的上市公司智能估值模型构建》（《证券信息技术》）， 六层架构为数据 A / 理解 B / 产业链 C / 估值 D / 推理 E / 输出 F；关联专利包括 “基于并行博弈的大语言模型动态估值算法及系统”（CN121765307A）、“多 Agent 协同控制”（ZL202410113286.8） 以及产业链智能挖掘相关专利。其多 Agent 采取“多空方并行博弈 + 高级 Agent 裁决”的路线。

本文共享“LLM + 多 Agent + 估值”的问题意识，但差异是结构性的：Agent 从“估值博弈的参与者”改为 结构化估值引擎的有界参数评审器；估值仍由引擎完成，Agent 不改估值叙事。

五层数学骨架

MATHEMATICAL BACKBONE

下列为 Unicode 近似，便于阅读；LaTeX 源码见 02-poster.tex。

L1层次 MoE：生命周期 × 方法z 为上层的阶段门控，m 为下层的方法门控；w 由可用性、适用度与先验 logit 决定。
L2模糊加权与 α-cut把权重与参数的不确定性提升为模糊数；M ≤ 4 时可顶点枚举或用 Charnes-Cooper 求精确端点。
L3三种合成语义线性池 / 对数池 / 专家乘积：分别对应“可解释基线”“分歧惩罚”“精度加权”。
L4指数点位合成用估值替代价格，按指数权重合成相对估值；价格加权口径只作对照。
L5Agent 受限算子专家提议 → 门槛 → 主审 → apply / shadow；caps 是信赖域，L1 稀疏鼓励少改。
EQ 01 · HIERARCHICAL MoE · LaTeX 源码见 02-poster.tex F(x; Θ) = Σ_z p(z | x) Σ_m w_{m|z}(x) · f_{m,z}(x; θ_{m,z}) w_{m|z}(x) = a_m(x) μ_{m,z}(x) e^{γ_m} / Σ_j a_j(x) μ_{j,z}(x) e^{γ_j}
EQ 02 · FUZZY WEIGHTED AVERAGE & α-CUT Ṽ = Σ_m w̃_m ⊗ ṽ_m / Σ_m w̃_m [V]_α = { Σ_m w_m v_m / Σ_m w_m : w_m ∈ [w_m]_α, v_m ∈ [v_m]_α } V̂ = ½ (V⁻_0.5 + V⁺_0.5), W_0.8 = (V⁺_0.1 − V⁻_0.1) / V̂
EQ 03 · INDEX COMPOSITION V_idx = P_idx · Σ_i w_i (V_i / P_i) / Σ_i w_i V_pw = P_idx · Σ_i w_i V_i / Σ_i w_i P_i
EQ 04 · BOUNDED AGENT OPERATOR T_apply(x) = F(x; θ + δ), δ = A R G Π(e), T_shadow(x) = F(x; θ) δ* = argmin_{δ ∈ C} L(θ + δ; e) + λ‖δ‖₁ C = { δ : |δ_j| ≤ c_j(s), θ + δ ∈ Θ_feas }
EQ 05 · SELF-ITERATION θ_{t+1} = θ_t + η_t A_t δ_t*
STATUS · 已实现 vs 论文扩展 已实现：清晰权重、三路加权、逐券情景区间、MC 3000、指数加权点位、shadow / apply、caps 与回滚。 论文扩展：模糊 α-cut、层次 MoE 的连续门控、三种合成语义的消融、Agent 受限算子的形式化与命题。 不能混写：不能把“提议的模糊层”写成“已上线能力”。
合成语义公式尺度性质分歧 / 极端值
线性池Σ w_m v_m正齐次；当前基线不惩罚分歧；极端值主导
对数池exp(Σ w_m ln v_m)正齐次；几何平均AM-GM 间隙隐含分歧惩罚；近零值剧烈拉低
专家乘积Π p_m(V|e)^{w_m}依赖似然尺度精度加权；相关专家会过度自信
PROPOSITION · 两个可检验性质 命题 1（可行域保持）：若 δ ∈ C 且 C ⊆ {δ : θ+δ ∈ Θ_feas}，则 apply 输出仍在可行域； shadow 对 θ 恒等，故估值不变。
命题 2（弹性上界）：若 F 可微、‖δ‖₁ ≤ c，则 |ln F(θ+δ) − ln F(θ)| ≤ L_θ c + o(‖δ‖)。 对 Gordon 终值 DCF，∂lnV/∂g ≈ s_T/(r−g)，∂lnV/∂r ≈ −D_mod；caps 并不小，必须配合主审、shadow 与回滚。

三阶段递进

THREE STAGES
STAGE I
基础模型
人写死参数与权重；三情景 + MC；行业参数底座。人的角色：定参。
STAGE II
Agent 化
专家提议 + 主审裁决 + 人审批；shadow / apply；证据门槛与 caps。人的角色：审批 / 否决。
STAGE III
自迭代优化
门控学习、时序校准、主动取证；阻尼、Polyak 平均、信赖域。人的角色：定目标 / 审计。

不确定性三情景 + MC 区间专家置信 + 证据强度 + caps校准后验 + α-cut + 区间覆盖
人的角色定参数、定权重审批 / 否决、处理例外定目标、审计、设边界
评价覆盖率、离散度采纳率、校准、周环比稳定泛化、稳健、跨期一致
当前状态已具备早期：shadow / apply 已落地雏形：每批快照，无跨批台账
CURRENT POSITION 阶段 II 的关键不是“让 Agent 更自由”，而是把自由变成可审计的边界：角色正交、证据门槛、幅度上限、主审裁决、baseline 回滚。 阶段 III 的关键不是“让系统自己调参”，而是让系统学会何时不该调。
