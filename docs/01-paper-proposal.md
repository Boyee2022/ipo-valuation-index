## 1. 一句话主张

> **企业估值是在模糊证据下的条件非线性映射；多 Agent 不是替代人的“估值 oracle”，而是有界、可审计的参数更新器；系统优化的方向是“人定 → Agent 提 → 系统学”。**

这句话包含三个可检验的主张。

**第一，估值是映射，不是查表。** 给定特征 \(x_i\)（财务、行业、生命周期、可比、舆情、市场状态），\(V_i\) 不可直接观测；我们只能构造
\[
V_i = F(x_i;\Theta)+\varepsilon_i,\qquad P_i=V_i(1+\eta_i),
\]
其中 \(P_i\) 是市价，\(\eta_i\) 同时包含噪声、流动性、情绪与真实错价。把 \(P_i\) 当作标签会把 \(\eta_i\) 一起学进去；把拟合点位贴近指数收盘当作目标，等于默认“市场永远对”。

**第二，多 Agent 是参数更新器，不是估值器。** 三个专家只在各自证据域内提出**有限幅度**的参数修改（可比权重、WACC、永续增速、舆情权重），主审只做 accept / clamp / reject；`shadow` 只留痕、不改参数，`apply` 回写并重跑，失败按 baseline 回滚。不是“让 LLM 自由定价”，而是“在可信域内提出可审计的局部修正”。

**第三，优化方向是“人定 → Agent 提 → 系统学”。** 阶段 I 人写死参数；阶段 II Agent 基于证据提议、人审批；阶段 III 系统学习门控、校准与取证。当前仓库处于阶段 II 早期：shadow/apply 已落地，但没有跨批参数台账，阶段 III 只是雏形。

## 2. 问题定义与三重模糊

### 2.1 三重模糊

估值系统面对的不是一个“输入确定、模型确定、目标确定”的优化问题，而是三重模糊。

| 模糊来源 | 具体表现 | 当前处理 | 残留风险 |
|---|---|---|---|
| **输入模糊** | 财报口径、数据缺失、新股与 ST、可比不足、舆情真假、时点不 PIT | 四层取值阶梯（L1 表述 → L2 采集 → L3 问询 → L4 默认）；缺失则跳过或降置信度 | 口径混杂、前视偏差、幸存者偏差 |
| **模型模糊** | DCF / 可比 / 舆情 / RIM / DDM / NAV / rNPV / SOTP 各有适用边界；生命周期判别本身有误差；方法间分歧不是“谁对谁错” | Layer 0 前提门 + 六阶段生命周期 + 方法路由 + 三路加权；不可用方法剔除后按剩余权重再归一 | 路由误判、方法权重主观、模型平均掩盖分歧 |
| **目标模糊** | 没有真值；市场价格不是价值；指数收盘不是“正确答案”；“准”与“稳”“可解释”“可审计”互相冲突 | 明确不以贴近收盘为目标；差异只诊断、不反向校正；多指标三角验证 | 评审追问“到底准不准”；指标选择争议；循环论证 |

### 2.2 不把“贴近市场价格”当目标

设逐券估值中枢为 \(V_i\)，收盘价为 \(P_i\)，定义**诊断残差**
\[
e_i=\frac{V_i}{P_i}-1,\qquad \bar e_w=\frac{\sum_i w_i e_i}{\sum_i w_i}.
\]
\(e_i\) 是“估值相对现价的偏离”，\(\bar e_w\) 是指数加权后的整体偏离。它们只用于**诊断**：偏离的方向、截面分布、行业集中度、对拟合点位的贡献。系统不根据 \(e_i\) 反向修改 \(V_i\)，也不把 \(P_i\) 当作监督信号。

价格含噪声与情绪；以收盘为目标会把“复制指数”当成“估值”，抹掉方法学信息；指数收盘还受成分、权重、停牌、除权影响。**无真值不等于无评估**：本文用合成基准、盲评、内部一致性评估过程质量，而不是用收盘价充当真值。

### 2.3 形式化的问题陈述

给定 \(N\) 只成分券、日期 \(t\)、证据集 \(\mathcal E_t=\{e_i\}\) 与参数 \(\Theta\)，系统输出 \(\hat V_i\)、区间 \([\underline V_i,\overline V_i]\)、置信度 \(c_i\)，以及指数拟合点位 \(V^{idx}\) 与三情景点位。学习/校准问题不是
\[
\min_\Theta \sum_i \bigl(V_i(\Theta)-P_i\bigr)^2,
\]
而是
\[
\min_\Theta\ \mathcal R(\Theta;\mathcal E)\quad \text{s.t.}\quad \Theta\in\Theta_{\text{feas}},
\]
其中 \(\mathcal R\) 是**校准、稳定、稀疏、可审计**构成的过程风险，\(\Theta_{\text{feas}}\) 是可行域（权重和为 1、WACC > 永续增速、参数上下限）。这是“没有真值的约束优化”，也是本文与常规监督学习的分水岭。

### 2.4 相关工作与方法论来源：从“估值博弈”到“参数评审”

据技能包 `methodology.md` 的文献映射，`llm-ipo-valuation` 的方法论来自国金证券李双宏、杨利国、王洪涛《基于大语言模型的上市公司智能估值模型构建》（《证券信息技术》），其六层架构为数据 A / 理解 B / 产业链 C / 估值 D / 推理 E / 输出 F；关联专利包括“基于并行博弈的大语言模型动态估值算法及系统”（CN121765307A）、“多 Agent 协同控制”（ZL202410113286.8）以及产业链智能挖掘相关专利。其多 Agent 采取“多空方并行博弈 + 高级 Agent 裁决”的路线，Agent 直接参与估值叙事与博弈。

本文与该路线共享“LLM + 多 Agent + 估值”的问题意识，但差异是结构性的：

| 维度 | 国金证券路线（据技能文档） | 本文 |
|---|---|---|
| Agent 角色 | 多空方并行博弈，高级 Agent 裁决 | 三专家只做**参数评审**，主审 accept/clamp/reject |
| 估值来源 | Agent 参与估值叙事 | 估值仍由结构化引擎完成，Agent 不改叙事 |
| 约束 | 博弈/裁决机制 | 证据门槛、severity caps、grid、shadow/apply、baseline 回滚、配置快照、人工采纳 |
| 场景 | 上市公司智能估值 | 指数成分券批量拟合、“估值替代价格”、五指数、三情景点位、指数加权 |
| 评估/形式化 | 以估值结果为重心 | 无真值评估协议 + 层次 MoE/模糊加权/受限 Agent 算子 |

因此，本文不是复现“多空博弈”，而是把 Agent 从“估值博弈的参与者”改为“结构化估值引擎的**有界参数评审器**”，并用工程协议与评估协议约束它。这一区分是 P2 贡献的核心，也是审稿人最可能追问的点。

## 3. 数学骨架

### 3.1 记号

| 记号 | 含义 | 取值/维度 |
|---|---|---|
| \(i\in I\) | 成分券 | \(i=1,\dots,N\) |
| \(x_i\in\mathcal X\) | 特征向量（财务、行业、生命周期、可比、舆情、市场） | 结构化 + 文本 |
| \(V_i\) | 不可观测的每股内在价值 | \(\mathbb R_+\) |
| \(P_i\) | 收盘价 | \(\mathbb R_+\) |
| \(m\in M\) | 方法族（DCF、可比、舆情、RIM、DDM、NAV、rNPV、SOTP） | 离散集合 |
| \(f_m(x;\theta_m)\) | 方法 \(m\) 的每股估值 | \(\mathbb R_+\) |
| \(a_m(x)\in\{0,1\}\) | 方法可用性（数据、Layer 0、路由） | 0/1 |
| \(\mu_m(x)\in[0,1]\) | 方法适用度 | 连续 |
| \(w_m\) | 门控权重 | 单纯形 |
| \(z\in Z\) | 生命周期阶段（六阶段） | 离散 |
| \(\theta\in\Theta\) | 参数（WACC、g、权重、倍数、增长率等） | 可行域 |
| \(e_i\) | 逐券证据包 | 结构化文本 |
| \(\delta\) | Agent 参数更新量 | 稀疏向量 |

### 3.2 层次化混合专家（Hierarchical MoE）

把生命周期 \(z\) 作为上层门控、方法 \(m\) 作为下层门控，得到
\[
F(x;\Theta)=\sum_{z\in Z}p(z\mid x)\sum_{m\in M}w_{m\mid z}(x)\,f_{m,z}(x;\theta_{m,z}),\tag{1}
\]
\[
w_{m\mid z}(x)=\frac{a_m(x)\,\mu_{m,z}(x)\,e^{\gamma_m}}{\sum_{j\in M}a_j(x)\,\mu_{j,z}(x)\,e^{\gamma_j}}.\tag{2}
\]
其中 \(p(z\mid x)\) 是生命周期后验，\(\gamma_m\) 是方法先验 logit（当前由三路权重近似），\(a_m\) 是硬可用性，\(\mu_{m,z}\) 是软适用度。层次结构的意义是：**方法权重不是全局常数，而是“阶段 × 方法”的条件权重**；同一套 DCF 参数在年轻成长与成熟稳定阶段不应共用。

当前实现是式 (1) 的工程近似：\(p(z\mid x)\) 近似为 one-hot 路由（Layer 1 六阶段判别；v3.29.1 起结构证据优先于盈利符号）；\(a_m\) 由 Layer 0 A/B 门、数据完备性与方法路由决定（金融走 RIM/DDM，管线药企可走 rNPV，多分部可走 SOTP，不可用方法剔除后按剩余权重再归一）；\(\mu_{m,z}\) 仍由规则与置信度近似。参数做分层收缩 \(\theta_{m,z}=\theta_m^0+\Delta_{m,z}\)，并约束 \(\lVert\Delta_{m,z}\rVert\le\tau_m\)，避免小样本阶段发散。

与普通 MoE 不同，这里的“专家”是有金融语义的估值方法，门控由制度与证据决定；可解释，但门控主观。

### 3.3 模糊加权平均与 α-cut

当前系统的权重是清晰的（30/50/20），区间主要来自 MC 与情景。论文要把“权重与参数的不确定性”显式提升为模糊数：
\[
\tilde V=\frac{\sum_m \tilde w_m\otimes\tilde v_m}{\sum_m\tilde w_m},\tag{3}
\]
其中 \(\tilde w_m,\tilde v_m\) 是三角/梯形模糊数，\(\otimes\) 是模糊乘法，除法按扩展原理理解。对水平 \(\alpha\in[0,1]\)，取 \(\alpha\)-cut：
\[
[V]_\alpha=\left\{\frac{\sum_m w_mv_m}{\sum_m w_m}:w_m\in[w_m]_\alpha,\ v_m\in[v_m]_\alpha\right\}.\tag{4}
\]
式 (4) 是分式规划；\(M\le 4\) 时可对权重盒顶点枚举，或用 Charnes-Cooper 变换求精确端点。工程上也可先用**安全外包络**
\[
[V]_\alpha\subseteq\left[\frac{\sum_m w_m^Lv_m^L}{\sum_m w_m^U},\ \frac{\sum_m w_m^Uv_m^U}{\sum_m w_m^L}\right],\tag{5}
\]
它一定包含真实 \(\alpha\)-cut，但可能偏宽；论文应报告精确端点与外包络的差距。去模糊化取
\[
\hat V=\frac12\left(V^-_{0.5}+V^+_{0.5}\right),\qquad
W_{0.8}=\frac{V^+_{0.1}-V^-_{0.1}}{\hat V},\tag{6}
\]
并报告 \([V]_{0.1}\)、\([V]_{0.5}\)、\([V]_{0.9}\) 三组区间。**状态**：式 (3)–(6) 是论文扩展，当前代码尚未实现；当前只有清晰权重、逐券情景区间与 MC 区间。论文不能把“提议的模糊层”写成“已上线能力”。

### 3.4 三种合成语义：线性池、对数池、专家乘积

单券综合目前是线性池：
\[
V_L=\sum_m w_mv_m,\qquad \sum_m w_m=1.\tag{7}
\]
三种池化代表三种不确定性语义。

| 语义 | 公式 | 尺度性质 | 分歧处理 | 极端值 | 前提 |
|---|---|---|---|---|---|
| **线性池** | \(V_L=\sum_m w_mv_m\) | 正齐次：\(F(kv)=kF(v)\) | 不惩罚分歧，差异被平均掉 | 高估值方法主导 | 权重和为 1；方法可加 |
| **对数池** | \(V_G=\exp(\sum_m w_m\ln v_m)\) | 正齐次；几何平均 | AM-GM 间隙隐含分歧惩罚 | 近零值剧烈拉低 | \(v_m>0\) |
| **专家乘积** | \(p(V\mid e)\propto\prod_m p_m(V\mid e)^{w_m}\) | 依赖似然尺度 | 精度加权；分歧体现在方差 | 相关专家导致过度自信 | 需校准似然与相关性 |

专家乘积在高斯情形下有闭式：
\[
V_P=\frac{\sum_m w_m\mu_m/\sigma_m^2}{\sum_m w_m/\sigma_m^2},\qquad
\sigma_P^{-2}=\sum_{m,n}\frac{w_mw_n\rho_{mn}}{\sigma_m\sigma_n}.\tag{8}
\]
忽略相关性会让方差随专家数虚假缩小，这是“多 Agent 一定更准”的常见幻觉。**线性池是当前可解释的基线，对数池是分歧惩罚的轻量替代，专家乘积是需要校准似然的高级形态**；三者应作为消融，而不是先验宣布谁最优。

### 3.5 指数点位合成

设指数收盘为 \(P^{idx}\)，成分权重为 \(w_i\)，逐券估值为 \(V_i\)，则指数加权拟合点位为
\[
V^{idx}=P^{idx}\cdot\frac{\sum_i w_i\left(V_i/P_i\right)}{\sum_i w_i}.\tag{9}
\]
跳过券不计入分子分母；若所有 \(V_i=kP_i\)，则 \(V^{idx}=kP^{idx}\)，这是尺度一致性的基本检验。价格加权对照口径为
\[
V^{idx}_{pw}=P^{idx}\cdot\frac{\sum_i w_iV_i}{\sum_i w_iP_i}.\tag{10}
\]
两者在 \(V_i=kP_i\) 时相同；一般情况下，式 (9) 按指数权重加权“相对估值”，式 (10) 按“权重 × 价格”加权，会高估高价股。论文以式 (9) 为主口径、式 (10) 为对照，并解释差异。

三情景点位由逐券区间按同一权重合成：
\[
V^{idx,s}=P^{idx}\cdot\frac{\sum_i w_i\left(V_i^s/P_i\right)}{\sum_i w_i},\qquad s\in\{\text{悲观},\text{基准},\text{乐观}\}.\tag{11}
\]
基准即式 (9)，悲观/乐观分别取逐券区间下/上端；报告时应同时给区间宽度与成分贡献，避免“点位看起来稳、内部其实很分歧”。

### 3.6 Agent 作为受限非线性算子

三个专家各自把证据映射为提议：
\[
P_k=\Pi_k(e_i^k),\qquad k\in\{\text{可比质量},\text{折现参数},\text{舆情}\}.\tag{12}
\]
门控 \(G\) 按置信度、证据中的具体数字、严重度、方向自洽、权限正交性筛选；主审 \(R\) 做 accept / clamp / reject；\(A\) 是“被接受坐标”的选择矩阵。于是
\[
T_{\mathrm{apply}}(x)=F(x;\theta+\delta),\quad \delta=A\,R\,G\,\Pi(e),\quad
T_{\mathrm{shadow}}(x)=F(x;\theta).\tag{13}
\]
`shadow` 是严格空操作：参数不变、估值不变，只多一条审计记录；`apply` 才改变参数并重跑。这个区分是因果识别的基础：`shadow` 提供“没有 Agent”的反事实，`apply` 提供“Agent 实际造成什么”的处理组。

把式 (13) 解释为带信赖域的稀疏局部更新：
\[
\delta^*=\arg\min_{\delta\in\mathcal C}\ \mathcal L(\theta+\delta;e)+\lambda\lVert\delta\rVert_1,\qquad
\mathcal C=\{\delta:\lvert\delta_j\rvert\le c_j(s),\ \theta+\delta\in\Theta_{\mathrm{feas}}\}.\tag{14}
\]
\(\lambda\lVert\delta\rVert_1\) 鼓励“少改、只改有证据的坐标”，\(c_j(s)\) 是按严重度分档的幅度上限。**注意**：系统没有真的求解式 (14)，专家提议是热启动，门控与主审是近似投影；论文应写“解释性对应”，不能写“已实现最优化”。

**命题 1（可行域保持）**  
设 \(\Theta_{\mathrm{feas}}=\{\theta:r>g+\epsilon,\ w\in\Delta,\ \lvert\theta_j\rvert\le B_j\}\)，其中 \(r\) 为 WACC/Ke，\(g\) 为永续增速，\(\Delta\) 为权重单纯形。若 \(\mathcal C\subseteq\{\delta:\theta+\delta\in\Theta_{\mathrm{feas}}\}\)，则 \(T_{\mathrm{apply}}\) 的输出仍在 \(\Theta_{\mathrm{feas}}\) 内；\(T_{\mathrm{shadow}}\) 对 \(\theta\) 恒等，故不改变估值。  
**条件**：caps 覆盖所有被接受坐标；主审执行 \(r>g\) 耦合约束；权重回写后重新归一。仓库已在回写层检查范围与 \(r>g\)，但“caps 与可行域的联合覆盖”仍需测试，不能只靠提示词。

**命题 2（弹性上界，Lipschitz 型）**  
设 \(F\) 对 \(\theta\) 可微，\(L_\theta=\sup_{\theta\in\Theta}\lVert\nabla_\theta\ln F(\theta)\rVert_1\)，且 \(\lVert\delta\rVert_1\le c\)。则
\[
\left\lvert\ln F(\theta+\delta)-\ln F(\theta)\right\rvert\le L_\theta\,c+o(\lVert\delta\rVert).\tag{15}
\]
对 Gordon 终值 DCF，若终值占比 \(s_T\)，则 \(\partial\ln V/\partial g\approx s_T/(r-g)\)，\(\partial\ln V/\partial r\approx -D_{\mathrm{mod}}\)。取 \(s_T=0.7\)、\(r-g=4\%\)，0.6pp 的 \(g\) 上限对应约 \(10.5\%\) 弹性；取 \(D_{\mathrm{mod}}=12\)，1pp 的 \(r\) 上限对应约 12%。这是**解析示例**，但说明 1pp WACC + 0.6pp g 足以让 DCF 估值移动 10%–20%，必须配合主审、shadow 与回滚。  
**假设**：\(F\) 可微、\(\delta\) 足够小、权重固定、\(g<r\)、Gordon 终值；路由到 RIM/DDM 或 rNPV 时需替换弹性公式。

### 3.7 自迭代：从“每批更新”到“系统学习”

若把每批的接受更新累积，得到
\[
\theta_{t+1}=\theta_t+\eta_tA_t\delta_t^*.\tag{16}
\]
不动点 \(\theta^\star\) 满足 \(\delta^\star(\theta^\star)=0\)（在 \(A_t\) 可逆、\(\eta_t>0\) 时），即“没有证据支持进一步修改”。但真实系统不会这么干净：**振荡**（证据阈值、严重度分档离散，\(\eta_t\) 过大时来回跳）、**漂移**（证据分布时变，\(\theta^\star\) 本身时变）、**过拟合**（同一批数据既提议又评估，会自我确认）。工程上可用阻尼 \(\eta_t=\eta_0/(1+t/T)\)、Polyak 平均 \(\bar\theta_T=\frac1T\sum_t\theta_t\)、信赖域回缩、连续多批一致才升级为正式参数。这些是阶段 III 的研究点。

| 维度 | 阶段 I：基础模型 | 阶段 II：Agent 化 | 阶段 III：自迭代优化 |

| 参数来源 | 人写死 + 行业参数底座 | 专家提议 + 主审裁决 + 人审批 | 门控学习 + 时序校准 + 主动取证 |
| 不确定性表达 | 三情景 + MC 区间 | 专家置信度 + 证据强度 + caps | 校准后验 + α-cut + 区间覆盖 |
| 人的角色 | 定参数、定权重 | 审批/否决、处理例外 | 定目标、审计、设边界 |
| 证据 | 固定输入 | 证据包 + 门槛 + 留痕 | 主动补证 + 反事实 + 外部盲评 |
| 评价 | 覆盖率、离散度 | 采纳率、校准、周环比稳定 | 泛化、稳健、跨期一致 |
| 主要风险 | 拍脑袋、口径混 | 自我确认、LLM 随机 | 反馈过拟合、循环论证 |
| 当前状态 | 已具备 | 早期（shadow/apply 已落地） | 雏形（每批快照，无跨批台账） |

阶段 II 的关键不是“让 Agent 更自由”，而是**把自由变成可审计的边界**：角色正交、证据门槛、幅度上限、主审裁决、baseline 回滚。阶段 III 的关键不是“让系统自己调参”，而是**让系统学会何时不该调**：门控学习、校准、主动取证、以及“无证据则维持”的默认策略。

### 7.2 指标

| 指标 | 定义 | 用途 | 方向 |
|---|---|---|---|
| 覆盖率 | \(C=\text{ok}/\text{total}\) | 系统可用性 | 越高越好，但需与跳过原因一起报告 |
| 跳过率 | \(S=\text{skip}/\text{total}\) | 失败结构 | 越低越好；按原因分层 |
| 离散度 | 逐券 \(e_i\) 或专家 \(\delta\) 的 IQR | 是否过度反应/过度保守 | 无绝对好坏，看稳定性与解释 |
| 置信度校准 | ECE、Brier（合成基准）；置信 vs 采纳（真实数据） | 置信是否可信 | 越低越好 |
| 周环比稳定 | \(\text{median}_i\lvert\theta_{i,t}-\theta_{i,t-1}\rvert\) | 参数是否抖动 | 越低越好，但不能以“不动”为目标 |
| 采纳率 | \(\text{adopted}/(\text{adopted}+\text{rejected})\) | 人工认可 | 越高越好；需防“全采纳”偏差 |
| 区间宽度 | \(W_{0.8}=(V^+_{0.1}-V^-_{0.1})/\hat V\) | 不确定性表达 | 在覆盖约束下越窄越好 |
| 弹性 | \(\partial\ln V/\partial r\)、\(\partial\ln V/\partial g\) | 参数敏感性 | 用于解释 caps 的必要性 |
| 诊断性市场指标 | \(\text{corr}(e_i,\text{PE}_i)\)、行业偏差、贡献 pp | 解释偏离结构 | **只诊断，不优化** |

### 7.3 三件套

**A. 合成基准（已知真值）**：用结构 DCF/RIM 生成 \(V_i^\star\)，再注入财报错报、可比缺失、增长率误判、单位错误、路由错误，测恢复误差 \(\lvert\hat V_i-V_i^\star\rvert/V_i^\star\)、80%/90% 区间覆盖率、路由准确率、参数恢复（WACC、g、权重）与对抗样本（负 FCFF、pre-revenue、ST、新股、极端偏离）。首轮 1,200 个案例（300 家 × 2 路由 × 2 噪声档），正式实验可扩到 3,000；每案例重复 20–50 次估计随机性。**它测的是“机制是否按设计工作”，不是“真实市场准不准”**。

**B. 人工盲评**：从五指数分层抽 100–150 个券-周，隐藏 Agent 建议与拟合点位，只给证据包与估值；4–6 名内部评审独立打证据充分性（1–5）、方向（-2…+2）、幅度（1–5）、置信（0–1）、是否采纳；两轮 Delphi + 仲裁；报告 Krippendorff \(\alpha\)、评分者间一致性与 Agent 置信的校准。内部员工、非敏感数据、匿名化；对外发表需单位审批与知情同意。

**C. 内部一致性**：同输入 5 个 seed 的估值/建议方差；股票顺序、单位缩放（元/亿元）、行业标签扰动的不变性；shadow 输出与无 Agent 完全一致；apply 失败后 baseline 恢复；八项机检通过率与字段完整性。

### 7.4 消融

| 消融 | 设置 | 想回答的问题 |
|---|---|---|
| 关专家 | 分别关可比/折现/舆情 | 每个专家的边际贡献 |
| 关主审 | 主审关闭（hold） | 主审是否真的在“减错” |
| shadow vs apply | 同批同券对照 | 回写是否改善过程指标 |
| 门槛 | 0.55 / 0.65 / 0.75 | 门槛与采纳率/校准的权衡 |
| caps | ×0.5 / ×1 / ×2 | 幅度上限是否抑制过度反应 |
| 池化 | 线性 / 对数 / 专家乘积 | 分歧惩罚与极端值 |
| 加权 | 指数加权 / 价格加权 | 合成口径的敏感性 |

**统计**：以券-周为单元做配对 bootstrap（按指数/行业分层），报告效应量与 95% CI；跨期比较用混合效应模型（指数、行业、阶段为随机效应）；多重比较用 BH-FDR。**预注册**主指标与停时规则，避免“跑完再挑指标”。

### 7.5 效度与反循环

内部效度靠 shadow 反事实、随机 seed、盲评与回滚测试；外部效度受限于“五指数但单一市场”，合成基准的生态效度有限，需跨市场/跨期复现；构念效度要回答“离散度、校准、稳定、采纳是否真的代表估值质量”，需质性访谈与案例。反循环来自证据同源、模型同源、评估者与开发者重叠；缓解靠异构模型、外部证据、盲评、预注册与负结果报告。

## 9. 风险与待决
