## 1. 本轮 demo 的边界

| 项 | 本轮 | 说明 |
|---|---|---|
| 数据 | 公开/构造数据 | 东财、腾讯、公开披露、自造样例 |
| 鉴权 | **不做** | 3089 服务保持无鉴权，仅可信内网 demo |
| 脱敏/隔离 | **不做** | 不接真实保密材料，不需要脱敏 |
| IPO 材料 | **不接真实材料** | 只用公开/构造公司样例演示 |
| 合规认证 | **不做** | 不作为验收项 |
| 自动交易/定价 | **不做** | 输出研究区间/诊断，不输出指令 |

**一句话**：demo 不碰真实保密数据，所以不需要鉴权/脱敏/隔离；等要接真实材料时再谈。

## 2. 对外表述

必须带：

> 本系统为探索性研究/工程 demo，估值结果不构成投资建议，不可作为发行定价依据。

禁止：

- “建议买入/卖出/加仓/减仓/撤退/入场/平仓/抄底/逃顶”；
- “国家队应撤退/平准基金应入场”等政策或交易指令；
- “保证收益/跑赢指数/预测点位”；
- 把 demo 区间写成“建议发行价”。

允许：

- “估值温度”“偏贵/偏便宜”“偏离结构”“不确定性高/低”“证据不足”；
- “研究区间”“方法分解”“敏感性”“可比证据链”。
