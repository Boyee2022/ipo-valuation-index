# IPO 定价规则与可比公司筛选检查清单

 > 每次估值必过此清单（SKILL.md Step 4/5 调用）。规则按板块区分，随时间更新，正式使用时以监管最新文件为准。
> 市场乘数法口径对齐中证协《非上市公司股权估值指引》(2025修订，中证协发〔2025〕86号)：可比公司 ≥3 家；价值乘数选取依据行业/盈利/经营阶段；经可比上市公司得到的乘数需考虑流动性差异。

## 1. 板块发行条件速查（中国 A 股注册制）

| 板块 | 定位 | 盈利要求（标准一示例） | 未盈利企业 | 定价机制 |
|---|---|---|---|---|
| 科创板 | 硬科技/前沿技术 | 近2年盈利且累计净利≥5000万；或市值+收入+研发组合 | ✅ 允许（第五套：市值≥40亿+核心产品空间） | 询价发行，无23倍窗口 |
| 创业板 | 成长型创新创业 | 近2年盈利累计净利≥1亿（红筹/特殊可豁免） | ✅ 允许（第三套：市值≥50亿+收入≥3亿） | 询价发行 |
| 主板 | 大盘蓝筹/行业龙头 | 近3年净利均为正、累计≥1.5亿，最近1年≥6000万 | ❌ 不允许 | 询价发行 |
| 北交所 | 创新型中小企业 | 近2年净利≥1500万，或营收≥1亿+经营性现金流为正… | 部分允许 | 定价/询价 |

## 2. 定价约束核心规则（注册制询价）

1. **可比锚定**：发行价格不得显著高于同行业可比上市公司估值水平；发行市盈率高于行业/可比中位数较多时须在《投资价值研究报告》中充分论证（实务中发行PE相对可比中位数偏离过大易被监管问询）。
2. **投资价值研究报告**：主承销商须出具，含可比公司估值比较、发行定价区间、风险揭示。
3. **四数参考值**（科创板/创业板）：剔除最高报价后中位数、加权平均数等"四数"孰低值与发行价的偏离区间是询价约束参考。
4. **募投匹配**：拟募资金额与募投项目投资额匹配；超募资金须说明用途。
5. **摊薄要求**：发行市盈率按发行后总股本（摊薄）口径计算；每股收益按发行后加权口径。
6. **锁定期**：控股股东/实控人 36 个月；核心技术人员（科创板）36 个月；首发前股份转让受限。
7. **破发红线**：上市后破发将影响后续再融资与中介声誉（市场约束，非硬规则）。

## 3. 发行市盈率偏离度预警（技能内置阈值）

| 发行PE相对可比中位数偏离 | 处理 |
|---|---|
| ≤ +10% | 正常 ✅ |
| +10% ~ +30% | 提示：需补充估值论证 |
| > +30% | 预警 ⚠️：显著偏离，报告须给出理由与敏感性 |
| < -20% | 提示：估值偏低，可能体现折价发行或基本面差异 |

## 4. 可比公司筛选标准（技能 Step 3 调用）

**硬条件（按优先级）**：
1. 同一产业链环节（如同为 AI 芯片设计，而非芯片代工）；
2. 同一技术/商业模式（Fabless vs IDM、授权 vs 自研）；
3. 营收规模同量级（±一个数量级内优先）；
4. 成长阶段相似（都处于成长期/成熟期）。

**软条件（加分项）**：客户结构相似、下游应用重叠、A 股上市（估值环境一致）。

**数量要求**：有效可比 ≥3 家；不足 3 家时按以下顺序降级并**在报告中标注置信度下降**：
1. 扩展到同行业上下游相邻环节；
2. 扩展到同技术平台不同应用；
3. 采用行业整体估值水平（申万一级/二级行业指数 PE/PS）。

**异常值处理**：对 PE/PS 使用 1.5×IQR 法剔除极端值；亏损公司 PE 不计入 PE 样本，但保留 PS/EV-EBITDA。

## 4b. 筛选证据链（v3.20.0 新增，与 §4 配套使用）

§4 回答「选谁」，本节回答「凭什么。」引擎侧由 `scripts/peer_screening.py` 执行，开关 `peer_screening.enabled`（缺省 false → 不激活、零数值影响）。

**四期七项判据（逐项留痕，缺数据只降级不阻断）**：

| 期 | 判据 | 判据内容 | 不通过的后果 |
|---|---|---|---|
| 一期 P0-1 | 长名单与剔除台账 | ①声明行业分类基准（SW_2021/CITIC/CSRC）②长名单 ≥ 2× 最终样本 ③有长名单必有剔除记录 ④剔除理由落 `REASON_TYPES` 枚举 ⑤样本覆盖率 | warning；分类基准缺失时**报告不得声称「已穷尽可比」** |
| 一期 P0-4 | 信息可得性截点 | 可比 `financial_period_end` 不得晚于估值基准日；滞后 >270 天须披露 | 晚于截点 = **用基准日后数据回填** → `violation`，`status` 至少降为 degraded |
| 二期 P0-2 | 规模双口径 5 倍 | 收入比与市值比分别计算，**取偏离 1 更远（更严）者为判定基数**，>5× 或 <1/5× | 须先收窄到产品档次更接近的子组，**不得直接用长名单中位作中枢** |
| 三期 P0-3 | 同一实体去重 | `legal_entity_id` 相同（或 code 去交易所后缀相同）只计一次；保留优先级 **A 股 > 市值更大 > 先出现** | 同一发行人占多票 + A/H 价差污染中位数 |
| 三期 P1-1 | 会计准则闸 | `standard` 与标的比对；跨准则标 `requires_reconciliation` | 净利润口径须调节后才可进 P/E 统计（**标记不删除**，PS/PB 可按需另用样本集） |
| 四期 P1-4 | 次新股剔除 | 上市 <12 月 → 剔除；12~24 月 → `watch`（须做含/剔双口径） | 次新 PE 含 30~50% 炒新溢价，直接纳入会抬高发行定价、放大破发风险 |
| 四期 P1-5 | 指数锚降权 | 级别 → 权重上限：primary 1.00 / fallback_l1 0.50 / fallback_l2 0.40 / **fallback_l3 0.30** | 指数为**全样本口径**，不得与精选可比同级呈现 |

**剔除理由枚举 `REASON_TYPES`**（自由文本不可统计，必须落枚举）：

```text
business_model 业务模式/技术路线不可比   product       产品档次/应用场景不可比
scale          规模量级差异过大          status        ST/*ST/退市/重大重组
data           财务期间或口径不可得      listing       上市时间不足（次新股）
accounting     会计准则不可比            duplicate     同一发行人重复（A/H/ADR）
other          其他（须在 reason 中说明）
```

**与 §4「1.5×IQR 剔除」的边界（重要）**：

IQR 是**纯统计判据**，它只把离群值砍掉让中位数"好看"，不区分「真高成长」与「亏损转盈的基数效应」。因此：

- IQR 剔除属**统计层**处理，不构成「筛选」——不得因为它把某家剔掉了，就在报告里说「该家不可比」；
- 真正的剔除必须走 §4b 的 `rejected[]` 台账并落 `reason_type`；
- 两者混用时的正确表述：「该样本在统计上被 IQR 剔除（PE 83.4×）」≠「该样本业务不可比」。

**状态机四态与建议权重**（`peer_screening.status` / `status_policy.weight_keep`）：

| status | 触发 | weight_keep | confidence_cap | 报告处置 |
|---|---|---:|---:|---|
| `ok` | n≥5 且无致命问题 | 1.00 | — | 正常出点估值 |
| `degraded` | 3≤n<5 / 规模超 5× / 截点违规 | 0.50 | 0.75 | 保留点估值，权重让出 50%，置信度折减 |
| `weak` | n<3 | 0.25 | 0.55 | 仅列区间，权重让出 75% |
| `unavailable` | n=0 | 0.00 | 0.40 | 不出点估值，权重全额让给其他方法 |

**诊断模式 vs 执行模式**：缺省诊断模式只产出 `status`/`problems`/`warnings`，**不改样本与数值**；`enforce.filter_sample=true` 才真正过滤（会改变数值），且**过滤后为空必须阻止并保持原样本**——不得因筛选把估值打空。

**报告披露要求**：报告中须有独立的「可比公司筛选证据链」小节（§4.1c），逐项列出长名单台账、截点校验、规模双口径、筛选例外与处置、指数锚降权。没有这一小节的可比法结论，视为**未完成**（监管对发行 PE 偏离的问询首先针对此）。

## 4c. 增速与永续增速参数（v3.21.0 新增，DCF 适用）

七条硬规则，逐条对应一个 `dcf_growth` 开关（开关名见末列）。**缺省全部关闭 = legacy 行为**，开启后报告 §6.2 / §7.3.4 同步披露。

| # | 规则 | 不满足的后果 | 开关（缺省） |
|---|---|---|---|
| R1 | **`g < WACC` 必须严格成立**。`g = WACC` 时分母为 0，`g > WACC` 时终值为负——越保守的假设反而抬高估值 | 原实现崩溃 / 负终值 / 归因写成「内在价值为负」 | `terminal_growth_guard`（off） |
| R2 | **永续增速缺省值不得越过自己设定的 GDP 上限**。缺省 6% 与 `gdp_cap 4.5%` 自相矛盾，实测使格力 +176.6% | 新案例默认高估 | `terminal_growth_default`（legacy_6pct） |
| R3 | **永续增速须有取值链**：用户显式 > 行业 `g_lt` > 通胀锚 2%。三角校准值是**短期增速外推**（可比中位 × 0.3），只能作校验参照 | 「可比中位 11.15% × 0.3 = 3.34%」直接当永续增速 | `terminal_growth_basis`（legacy） |
| R4 | **行业 `g_lt` 必须被消费**。原实现全库 0 处消费 → 家电/白电类目的 `g_lt` 是死值 | 行业参数底座形同虚设 | 同 R3（chain 模式第 2 档） |
| R5 | **永续增速须进入三情景**，bull 侧受 GDP 上限约束。假设层 `impact_map.terminal_growth_adj_pp` 必须被消费 | bull 终值占比 81.6% 却零调整；死字段 | `terminal_growth_scenario_mode`（flat） |
| R6 | **终值占比须可解释**（四档：<40% 过低 / 40–75% 区间 / 75–85% 偏高 / >85% 极端）。>85% 只报 error + 置信度封顶，**不阻断** | 只算不判，92.2% 也无告警 | `tv_share_guard`（false） |
| R7 | **历史增速先判形态、再定规则**。含正含负（正负切换）**不得取平均、不得机械外推**；全正时若区间跨度 >10pp 禁止外推加速度 | 无 `growth_forecast` 时复制首值（格力会取可比 11.15%） | `growth_history_shape`（off） |

**显式期技术四则**（B 组）：

- **B1 路径不截断**：用户给 7 年就用 7 年，只取前 3 年会把后 2 年静默丢弃；
- **B3 四阶段显式期 10 / 8 / 6 / 4（v3.27.0 重标定）**：原 10/6/4或7/5 会因 B3 单独抬高 mature 而出现「成长期 6 < 成熟期 7」的倒挂——越确定的公司要求预测得越远。现统一为 startup 10 / growth 8 / mature 6 / decline 4，并加导入期断言锁死 `startup ≥ growth > mature ≥ decline`；`lifecycle_mature_n_mode` 缺省改为 `table`，`legacy_4`／`cva_7` 仅作显式 opt-in。★注意：n 改的是**价值来源的可审计性**（美的 71.3% → 63.6%），中枢仅动 ±0.6%；
- **B5 末段增速强制落在 tg**：`exp`/`mean_revert`/`s_curve` 都是渐近线，数学上永不到达 tg，与「成熟期增速已稳定」的定义矛盾；
- **B4 情景步长按 σ**：固定 ±10pp 会让 bear 首年增速突破历史极值（格力 σ=9.62pp → clamp 5pp）。历史不足 3 期回退 fixed 并告警。

**市场隐含 g\*（A7）是诊断工具，不是参数**：`g* = 反解(市值 − 净现金 − 显式期现值)`。`g* < −5%` 或残值 ≤ 0 表示**分歧不在永续假设上**——此时无论把 tg 调到多低都压不到市价，须回头质疑现金流路径本身。

**报告披露要求**：开启任一开关后，§7.3.4 须给出「取值链表 + 三情景 tg + 终值占比档位 + g\*」。若终值占比落「极端」档而报告未解释 `tg` 依据，该 DCF 结论视为**不可用**。

## 5. 未盈利企业（科创板/创业板适用）

- 禁用 PE/PEG，主方法改为 **PS / EV-Sales / PFCF**；
- 补充检查：市值-收入组合标准（如科创板第五套：市值≥40 亿 + 核心技术产品已获市场认可）；
- 报告须单列"未盈利估值说明"段落，解释为何 PS 合理、与可比成熟公司 PS 的差异。

## 6. 市场乘数口径统一（v3.3，中证协市场乘数法口径）
- **PE**：分子用归属于母公司净利润（非全部净利润）；目标公司盈利为正且可比杠杆结构相似；异常利润需正常化调整。
- **PB**：分子为归属于母公司所有者权益（净资产）；适用于重资产/金融/经营不佳可能清算场景（配合净资产法）。
- **EV/EBITDA**：分子 EV=市值+净债务，分母 EBITDA 口径一致；高折旧/高杠杆行业优先于 PE（剔除折旧与杠杆差异）。
- **PS/EV-Sales**：未达可持续利润阶段用 EV/Sales；收入指标可考虑市场参与者收购时可实现收入。
- 目标公司与可比公司指标须**同期**（历史或预期口径一致）；数据来源与日期在 comparables.note 中标注。
- **全球行业维度（v3.11 修订 2c）**：目标公司处于**全球化竞争行业**（半导体、消费电子、创新药、互联网、汽车等）时，可比集**必须纳入海外龙头**（≥1/3 可比为海外标的），并按市场分组呈现（`exchange: CN/HK/US/KR`）：
  - 业务最可比优先于市场环境可比——如 DRAM IDM 的全球可比是美光/SK海力士/三星（同为重资产 IDM），而非仅 A 股二线标的；
  - 海外与境内倍数差异（流动性溢价/成长溢价/会计口径 GAAP vs CAS/税率）须在报告显式解释（引擎 `comparable_group_gap` 输出估值差%）；周期股海外龙头 TTM PE 与 A 股差异可达 60%+，属正常口径差而非错误；
  - 海外可比用 ADR/本地代码均可（`fetch_data.py` 支持 US./HK 前缀；韩股用 ADR 或手动输入+note）。

## 7. 每次估值必须核对的监管要素

- [ ] 发行前股本、发行股数、发行比例（首发比例规则：≥10%且≤...，股本不同要求不同）；
- [ ] 摊薄后 EPS、发行后总市值、发行市盈率；
- [ ] 募资额 vs 拟募资额（超募/缩募）；
- [ ] 募投项目达产年限与增量贡献；
- [ ] 锁定期与首发流通比例 → 流动性折价；
- [ ] 可比公司中位数与行业平均（申万行业）；
- [ ] 上市以来可比公司近期 IPO 定价/上市首日表现（市场窗口参考）。

## 8. 中证协《非上市公司股权估值指引》(2025修订) 四方法落地（v3.5）

> 依据：中证协发〔2025〕86号，2025-06-01 施行。适用：非上市股权估值（含 IPO 前融资、并购、尽调场景）。

- **最近融资价格法（第八条）**：估值日距融资 ≤1 年且无重大事件的，投资成本/融资价格可作为公允价值最佳估计；
  必须完成 **9 项排除情形检查**（引擎 RFP_EXCLUSION_DEFS E1-E9），命中任一即不适用；老股/新股价格差异需分析原因。
- **回购价格法（2025 新增）**：业绩未达预期或未按时 IPO 触发回购条款时采用；传统估值与回购价值**孰高**，
  结合实现条件概率加权（引擎 repurchase_valuation）。
- **流动性折扣（第二十/二十一条）**：非上市股权相对上市公司需流动性折扣——看跌期权模型（引擎
  discount=2N(v√T/2)−1，v√T 用 Longstaff 公式）或经验数据（实务约 10%-50%）；仅对"经可比上市公司得到的乘数"施加，
  DCF 与一级市场锚不折（引擎 liquidity_discount，与 ipo_check.float_ratio 分层）。
- **净资产法（成本法）**：企业价值主要来源于资产时适用（重资产/投资控股）；经营不佳/可能清算企业时作为估值下限
  （引擎 nav_valuation，liquidation_scenario=true 提示）。
- **估值频率与数据时效（第六条）**：至少每半年估值一次；估值数据距基准日原则上不超过 1 年。
